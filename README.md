# :gun: Unity Weapon System
A modular and flexible Unity package for managing weapons.

## Overview
The **Unity Weapon System** provides a simple yet powerful structure for handling weapons in your game. It supports different weapon types, attack mechanics, upgrades, and custom behaviors out-of-the-box.

Full [Documentation] is available with step-by-step setup and usage instructions.

## Features
- Handle attack input and cooldowns,
- Customize weapon stats and behaviors,
- Expand easily with ScriptableObjects and custom C# classes.

## Installation

There are two ways to install the package:

### Local Installation
To install the package locally:

1. Open `Window -> Package Manager`.
2. Click the `+` button in the top-left.
3. Select `Add package from disk...`.
4. Navigate to the `com.seaqqull.unity-weapon` folder.
5. Select the `package.json` file.

### GitHub via Package Manager

1. Open `Window -> Package Manager`.
2. Click the `+` button in the top-left.
3. Select `Add package from git URL...`.
4. Enter "https://github.com/Seaqqull/unity-weapon.git?UnityWeapon/Assets/com.seaqqull.weapon".
5. Click `Add` button.
